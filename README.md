*Pancake Recipe Website*:

A simple HTML and CSS project that displays an American-style pancake recipe.  
This was one of my early practice projects for learning basic web development structure, layout, and styling.

## Features
- Brief introduction to pancakes
- A descriptive image of an american style pancake
- Ingredients section separated into wet and dry ingredients  
- Step-by-step instructions   
- Basic CSS styling with shadows and rounded corners

## Technologies Used
- HTML5  
- CSS3  

## Purpose
This project helped me practice:
- Structuring a webpage using semantic HTML
- Styling elements with CSS
- Working with images
- Creating readable recipe layout
